# 🚀 سجلي - تطبيق تنظيم المواعيد

تطبيق Flutter لتنظيم المواعيد وإدارة الدعوات باللغة العربية مع دعم كامل للتقويم الهجري.

## ✨ الميزات الرئيسية

- 🗓️ **إدارة المواعيد**: إنشاء وتنظيم المواعيد بسهولة
- 📨 **نظام الدعوات**: دعوة الأصدقاء والمتابعة
- 📅 **التقويم الهجري**: دعم كامل مع إمكانية التصحيح
- 🔍 **البحث الذكي**: بحث متقدم باللغة العربية
- 🤖 **الإدخال الذكي**: مساعد AI لإنشاء المواعيد
- 🔔 **الإشعارات**: تنبيهات ذكية للمواعيد
- 👥 **الشبكة الاجتماعية**: متابعة المستخدمين والتفاعل

## 🏗️ هندسة المشروع

المشروع يتبع Clean Architecture مع تنظيم Feature-First:

```
lib/
├── core/           # الأساسيات المشتركة
├── features/       # الميزات (كل تبويب منفصل)
├── models/         # نماذج البيانات
├── routes/         # التوجيه
└── state/          # إدارة الحالة
```

## 🚀 البدء السريع

```bash
# استنساخ المشروع
git clone [repository-url]

# تثبيت التبعيات
flutter pub get

# تشغيل التطبيق
flutter run
```

## 📱 المتطلبات

- Flutter 3.9.0+
- Dart 3.0.0+
- Android SDK 21+
- iOS 12.0+

## 🔧 التقنيات المستخدمة

- **Frontend**: Flutter
- **Backend**: PocketBase
- **State Management**: Provider
- **Local Storage**: SharedPreferences + SQLite
- **Networking**: HTTP
- **Calendar**: Hijri Package
