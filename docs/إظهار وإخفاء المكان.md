# Implementation Plan - Toggle for Appointment Location Visibility

We are implementing a feature that allows users to toggle the visibility of location information (region and building) on all appointment cards on/off. When toggled off, location details will be hidden from everyone (including the user themselves). By default, anonymous (unauthenticated) visitors will always have the location hidden.

## Proposed Changes

### Core / Providers

#### [MODIFY] [settings_provider.dart](file:///Users/hussain/Documents/sijilli/lib/core/providers/settings_provider.dart)
- Add preference key: `static const String keyShowLocationInfo = 'show_location_info';`
- Add boolean state variable: `bool _showLocationInfo = true;`
- Add getter: `bool get showLocationInfo => _showLocationInfo;`
- Add loader logic inside `loadSettings()`: `_showLocationInfo = prefs.getBool(keyShowLocationInfo) ?? true;`
- Add setter method:
  ```dart
  Future<void> setShowLocationInfo(bool enabled) async {
    if (_showLocationInfo == enabled) return;
    _showLocationInfo = enabled;
    notifyListeners();
    final prefs = await SharedPreferences.getInstance();
    await prefs.setBool(keyShowLocationInfo, enabled);
  }
  ```

## Verification Plan

### Automated Tests
- Run `flutter analyze` to ensure no warnings or compilation issues.
- Run `flutter test` (if applicable) to verify no regressions.

### Manual Verification
1. Open the app as a logged-in user. By default, location information should be visible on the home screen cards.
2. Tap the menu button on the top-left of the home screen and choose "إخفاء معلومات المكان" (Hide location information).
3. Verify that the location line (region and building) disappears from all cards, and the card height shrinks accordingly.
4. Tap the menu button again, and verify the menu option has changed to "إظهار معلومات المكان" (Show location information).
5. Choose it, and verify that location details are visible again.
6. Log out or browse as an anonymous guest, and verify that the location is hidden unconditionally regardless of the local setting.
