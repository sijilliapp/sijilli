# Implementation Plan - Google Keep-style Article Tagging (Updated)

Add a robust, Google Keep-style article tagging (category capsules) system in the **Sijilli** application. Based on user feedback:
1. **Public Stamped Tags**: Tags are attached to the articles and are visible to anyone visiting the article or author's profile.
2. **Personal Tag Library**: Authors manage their own custom "library of stickers" (e.g., History, Science, Art) to choose from when tagging articles.
3. **Manual DB Schema Entry**: Database changes will be documented clearly for manual entry in PocketBase.

---

## User Review & Decisions

### 1. Tag Ownership & Visibility (Aligned)
* Tags belong to the article. When a visitor views a public article or the author's public profile, they see these articles stamped with the author's chosen tag capsules.
* Each user maintains their own library of tags (like ready-made stickers on a shelf) to reuse.

### 2. Database Modifications (To be entered manually)
* We will define the exact collections and fields for PocketBase below.

## PocketBase Schema Updates (Apply Manually)

Please open your PocketBase Admin UI and make the following changes:

### Step 1: Create the `tags` Collection
1. Click **New Collection**.
2. Set **Name**: `tags`
3. Set **Type**: `Base`
4. Add the following fields:
   * **Field 1**: 
     * Name: `name`
     * Type: `Plain text`
     * Options: `Required`, `Non-empty`
   * **Field 2**: 
     * Name: `color`
     * Type: `Plain text`
     * Options: `Required` (Format: HEX code like `FF4F79` or `4F46E5` without the `#` prefix)
   * **Field 3**: 
     * Name: `user`
     * Type: `Relation`
     * Options: Collection: `users`, `Single relation` (uncheck "Allow multiple relations"), `Required`

### Step 2: Update the `articles` Collection
1. Select the `articles` collection.
2. Click **Edit Collection**.
3. Add a new field:
   * Name: `tags`
   * Type: `Relation`
   * Options: Collection: `tags`, `Max Select: Unlimited` (check "Allow multiple relations")
