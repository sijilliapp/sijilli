# 📁 مجلد الثوابت

## 🎯 الغرض
يحتوي على جميع الثوابت المستخدمة في التطبيق لضمان الاتساق وسهولة الصيانة.

## 📄 الملفات

### `app_colors.dart`
- ألوان التطبيق الأساسية
- ألوان الثيم الفاتح والداكن
- ألوان الحالات (نجاح، خطأ، تحذير)

### `l10n/` (خارج مجلد الثوابت)
- جميع النصوص المعروضة للمستخدم (دعم لغات متعددة)
- ملفات `app_ar.arb` و `app_en.arb`
- يتم استخدام `context.l10n` بدلاً من الثوابت الجامدة

### `app_dimens.dart`
- القياسات والمسافات
- أحجام الخطوط
- أبعاد العناصر

### `app_styles.dart`
- أنماط النصوص
- أنماط الأزرار
- أنماط البطاقات

## 🔧 كيفية الاستخدام

```dart
// استخدام الألوان
Container(color: AppColors.primary)

// استخدام النصوص (L10n)
Text(context.l10n.login)

// استخدام القياسات
Padding(padding: EdgeInsets.all(AppDimens.padding))

// استخدام الأنماط
Text('مرحبا', style: AppStyles.headlineLarge)
```

## ⚠️ قواعد مهمة

1. **لا تستخدم قيم مباشرة** - استخدم الثوابت دائماً
2. **أسماء واضحة** - اختر أسماء وصفية
3. **تجميع منطقي** - جمع الثوابت المتشابهة
4. **توثيق واضح** - اشرح الغرض من كل ثابت
